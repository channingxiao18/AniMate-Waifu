## 关于

AniMate Waifu 把一个 3D 二次元角色放上你的 Windows 或 Mac 桌面——一个透明的、始终置顶的伙伴：它会追踪你的鼠标、被触摸时有反应、跟着音乐跳舞，还能用文字或语音和你对话。

它不是壁纸，不是浏览器里的聊天标签页。角色就生活在你的桌面上、窗口前面，陪着你工作。

**本仓库是 AniMate Waifu 的官方主页。** 应用本体为闭源；Bug 反馈、功能建议和提问请提 [Issues](../../issues)，我们都会看。

## 亮点

- **你自己的角色，而不是 DLC 阵容** —— 导入任意 VRM 模型：VRoid Studio 做的、约稿的、下载的都行
- **真对话，不是预设台词** —— AI 文字 + 语音对话，每个角色可配置专属 TTS 音色
- **一支舞，全角色通用** —— 导入 VRMA 舞蹈文件，库里哪个角色都能跳
- **是资产库，不是设置面板** —— 工坊统一管理角色、动作、舞蹈、舞台，带 3D 预览
- **Windows 和 Mac 功能一致** —— 仅分发方式不同
- **一次买断** —— US$9.90 解锁全部，无订阅，14 天退款

## 功能

### 角色与所有权
- **VRM 0.x 与 VRM 1.0 导入**（Pro），含 VRoid Studio 当前导出的版本，支持 MToon / MToon10 着色器
- 针对 VRoid Studio 模型的顺畅工作流
- 角色库：导入的每个模型都集中管理
- 每个角色可单独设定人格、声音与陪伴风格
- 免费附赠两个内置角色

### 桌面存在感
- 透明、始终置顶的叠加层——角色站在桌面上，不像一个窗口
- 鼠标穿透模式，完全不挡操作
- 位置与尺寸在重启后保持不变
- 系统托盘图标，支持开机自启
- 界面支持 8 种语言：简体中文、English、日本語、한국어、Français、Deutsch、Español、Português

### 互动
- 鼠标追踪——视线和头部跟随你的光标
- 摸头、拖拽、缩放，均有互动反应
- 右键菜单快捷操作
- 自然的待机动作随机轮换，不会一直重复同一个片段
- 睡眠模式——角色会犯困、会休息
- Q 版（Chibi）模式——把角色变小只
- 性格预设与互动强度可调：安静还是活泼，你说了算

### 舞蹈与音乐
- 音乐律动——放什么歌，它就跟着动
- 免费版含内置舞蹈
- **VRMA 舞蹈导入**（Pro）——把自己收藏的舞蹈文件带进来
- **一支舞，任何角色** —— 舞蹈不和单一模型绑定，可套用到库里所有角色

### 工坊
- 角色、动作、舞蹈、舞台统一管理
- 3D 预览，可旋转缩放
- 舞台导入与切换（Pro）——图片 / 视频背景，角色在场景里表演而不是浮在壁纸上

### AI 对话
- 文字 + 语音对话，直接驱动角色本人——说话的就是这个角色，不是角落里的聊天机器人
- 每个角色可配置专属 TTS 音色——听到你熟悉的声音
- 口型、表情、字幕跟随对话变化
- 人格与陪伴风格按角色设定
- 聊天记录保存在你自己的设备上
- 对话需要联网，并配置受支持的 AI / 语音服务

### 性能与信任
- 性能模式与 Q 版模式可为低配置设备降负载（实际占用取决于模型与硬件）
- 无需管理员权限，不装驱动，不修改受保护的系统文件
- 不捆绑任何第三方软件
- 仅通过微软商店（签名）与官网直装包（附 SHA256 校验值）分发

### 平台
- Windows 10/11（64 位）—— 微软商店或官网直装
- macOS 12 或更高版本（Apple Silicon）—— 官网直装
- 两端功能完全一致

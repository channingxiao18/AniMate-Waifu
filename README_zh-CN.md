## 关于

AniMate Waifu 把一个 3D 二次元角色放上你的 Windows 或 Mac 桌面——一个透明的、始终置顶的伙伴：它会追踪你的鼠标、被触摸时有反应、跟着音乐跳舞，还能用文字或语音和你对话。

它不是壁纸，不是浏览器里的聊天标签页。角色就生活在你的桌面上、窗口前面，陪着你工作。

**本仓库是 AniMate Waifu 的官方主页。** 应用本体为闭源；Bug 反馈、功能建议和提问请提 [Issues](../../issues)，我们都会看。

## 功能

### 你的角色：VRM 导入与 VRoid Studio
- **VRM 0.x 与 VRM 1.0 导入**（Pro），含 VRoid Studio 当前导出的版本，支持 MToon / MToon10 着色器
- 针对 VRoid Studio 模型的顺畅工作流
- 角色库：导入的每个模型都集中管理
- 每个角色可单独设定人格、声音与陪伴风格
- 免费附赠两个内置角色

### 桌面存在感
- 透明、始终置顶的叠加层——角色站在桌面上，不像一个窗口
- 鼠标穿透模式，完全不挡操作
- 位置与尺寸在重启后保持不变
- 系统托盘图标，支持开机自启
- 界面支持 8 种语言：简体中文、English、日本語、한국어、Français、Deutsch、Español、Português

### 互动
- 鼠标追踪——视线和头部跟随你的光标
- 摸头、拖拽、缩放，均有互动反应
- 右键菜单快捷操作
- 自然的待机动作随机轮换，不会一直重复同一个片段
- 睡眠模式——角色会犯困、会休息
- Q 版（Chibi）模式——把角色变小只
- 性格预设与互动强度可调：安静还是活泼，你说了算

### 舞蹈与音乐
- 音乐律动——放什么歌，它就跟着动
- 免费版含内置舞蹈
- **VRMA 舞蹈导入**（Pro）——把自己收藏的舞蹈文件带进来
- **一支舞，任何角色** —— 舞蹈不和单一模型绑定，可套用到库里所有角色

### 工坊
- 角色、动作、舞蹈、舞台统一管理
- 3D 预览，可旋转缩放
- 舞台导入与切换（Pro）——图片 / 视频背景，角色在场景里表演而不是浮在壁纸上

### AI 陪伴与对话

### AI 陪伴能力细项

"能对话"在功能表里常常被压成一行，这里把它拆开：

- **文字 + 语音** —— 打字或直接说话，回答用角色自己的声音
- **语音全双工** —— 它说话时你也可以说，不必等它说完
- **支持打断** —— 随时插话，它会停下来回应你刚说的，而不是把预设台词念完
- **记忆** —— 它记得你们聊过什么，对话接着上次继续，而不是每次重开
- **世界书 / 自定义设定** —— 挂载你自己的设定、背景与角色知识，回复始终保持在角色里；与 AI 角色扮演工具用的是同一套 "world book" 格式
- **音色定制** —— 每个角色一个 TTS 音色，两个角色不会听起来像同一个人
- **身体跟随回答** —— 口型、表情、动作由对话实时驱动，不是另跑一条循环动画

各有各的好：想读源码、装 Mod 选 MateEngine；想要官方授权角色选 Desktop Mate。AniMate Waifu 为**你自己的角色 + 真实对话**而生——AI 跑在云端，不需要下载大模型，也没有本地推理在后台占资源。完整对比：[AniMate Waifu vs Desktop Mate](https://getanimate.app/desktop-mate-alternative)。

## 常见问题

**免费吗？** 免费，有边界：两个内置角色、完整互动、AI 对话、桌面跳舞都不限时免费。Pro 为一次买断。

**支持哪些 VRM 版本？** VRM 0.x 与 VRM 1.0 都支持，含 VRoid Studio 当前导出的版本。PMX / FBX 需先转换为 VRM。

**模型从哪来？** 用 [VRoid Studio](https://vroid.com/studio) 自己做（免费），或逛逛[社区免费模型库](https://getanimate.app/models)——模型由社区制作，许可能否商用、能否再分发各不相同。

**AI 对话会把数据传到哪里？** 对话依赖云端、需要联网；聊天记录只保存在你自己的设备上。

**它记得之前的对话吗？** 记得——记忆让对话跨会话延续；你也可以挂载自定义世界书，让角色的设定与背景保持一致。

**界面支持哪些语言？** 简体中文、English、日本語、한국어、Français、Deutsch、Español、Português，随时切换。

**请尊重模型版权。** 只使用你有权使用的角色；许可不允许传播的模型请不要转发。

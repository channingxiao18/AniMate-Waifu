## About

AniMate Waifu puts a 3D anime character on top of your Windows or Mac desktop — a transparent, always-on-top companion that tracks your cursor, reacts when you touch it, dances to your music, and talks back in text or voice.

It is not a wallpaper, not a browser chatbot tab. The character lives on your desktop, in front of your windows, while you work.

**This repository is the official home of AniMate Waifu.** The app itself is closed-source; use [Issues](../../issues) for bug reports, feature requests and questions. We read everything.

## Why AniMate Waifu

- **Your own character, not a DLC lineup.** Import any VRM model — one you built in VRoid Studio, commissioned, or downloaded. Both **VRM 0.x and VRM 1.0** are supported, including what current VRoid Studio exports.
- **Real conversation, not preset lines.** Text and voice chat powered by AI, with custom TTS voices per character, and expressions, motion and lip movement that follow what you say.
- **One dance, any character.** Import VRMA dance files and apply them to any model in your library — a dance is yours to reuse, not welded to one character.
- **Stages, not wallpaper.** Image and video backgrounds turn your desktop into a small stage.
- **A library, not a settings panel.** The Workshop keeps characters, motions, dances and stages in one place, with previews.
- **The same app on Windows and Mac.** Same characters, same dances, same Workshop on both. Only the delivery differs — Microsoft Store on Windows, direct download on Mac.
- **One-time purchase.** US$9.90 once unlocks everything. No subscription, 14-day refund.

## Features

**On your desktop**
- Transparent, always-on-top overlay that never blocks your work (click-through supported)
- Cursor tracking, head pats, drag and resize
- Idle motion, sleep mode, chibi mode, performance mode
- Music reactivity — the character dances to whatever is playing
- Position and size remembered between sessions

**Your characters**
- VRM 0.x and VRM 1.0 import (MToon / MToon10 shaders)
- Persona, voice and companionship style configured per character
- Workshop library with previews for characters, motions, dances and stages

**Dance & stages**
- Import VRMA dance files, apply to any character
- Built-in dances included in the free tier
- Image and video backgrounds as stages

**AI conversation**
- Text and voice chat that drives the character's body
- Custom TTS voices — hear a voice you recognise
- Expressions, motion and mouth movement follow the conversation
- Chat history stays on your device (chat requires an internet connection)

## Install

1. **Get AniMate Waifu** — from the [Microsoft Store](https://apps.microsoft.com/detail/9PHRL2T3F0BS) (Windows, recommended) or the [direct installer](https://getanimate.app/download).
2. **Pick a spot** — put the character wherever you like. It stays there between sessions.
3. **Bring your favourite** — import a `.vrm` file inside the app. See the [VRM import guide](https://getanimate.app/guides/import-vrm-model) and the [free model library](https://getanimate.app/models) if you don't have a model yet.

**System requirements:** Windows 10/11 (64-bit) · macOS 12 or later on Apple Silicon. Intel Macs are not supported.

## FAQ

**Is it free?** Yes, with limits: two built-in characters, the full interaction set, AI chat and desktop dancing cost nothing, with no time limit. Pro is a one-time purchase.

**Which VRM versions work?** Both VRM 0.x and VRM 1.0. PMX and FBX models need to be converted to VRM first.

**Where do I get a model?** Make one in VRoid Studio (free), or browse the [free model library](https://getanimate.app/models).

**Does the AI chat send my data somewhere?** Chat is cloud-connected and needs internet; your chat history is stored locally on your device.

**Please respect model rights.** Only use characters you have the rights to. Don't redistribute models whose license doesn't allow it.
